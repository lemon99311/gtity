## 现在是什么

`index.html` 是 **5,086 字节的 HTML 骨架**：2 个 JSON 空壳 + 1 个 `<script type="module">` 入口，没有内联可执行 script、没有内联 style。原 66 个内联块（33 script + 33 style）已外置为 `src/层/` 下 64 个 ESM / CSS 模块，按原文档顺序由启动入口逐个 `import` 同步求值。

业务实现进了产物：5 个 `layer-*` JS chunk 合计 833 KB、4 个 CSS 合计 436 KB；`boot` 只剩 9 KB 接线；8 个按需 chunk 仍由动态 import 拉起。

**基线改写共 3 处**：2 处都在 `src/层/S046-script-tpl-b5-handoff.js`（`layerRows()` 与 `runCheck('exports')` 的 DOM 层扫描换成层登记注册表），第 3 处在 `src/层/S038-script-L3951.js`（Formula 公式引擎抽离为 `src/业务/表单/公式引擎.js`，按四块重组第一阶段）。其余 62 个块逐字未动。代价与限定见 `09` 第 6 节与 `10_按四块重组.md`。

## 时序怎么保住

1. 启动入口**第一个** import 是层注册表；`vite.config.js` 把它归到首个业务段 `layer-a-early`，保证先于所有业务层求值。若留在入口 chunk，ESM 规定静态依赖先求值，业务层会读到未定义的注册表（第一次分 chunk 就踩过这个坑）。
2. 64 条 `import '../层/Sxxx'` 按原文档顺序同步求值，等价于原来的内联脚本顺序：全局出口挂载顺序、`boot()` 同步首屏、`LAYERS=layerRows()` 冻结基线都不变。
3. 注册表 42 槽位逐项对齐基线冻结层序；其中 3 个运行时注入的样式层插在 index 31–33，getter 按 DOM 实况纳入，之后注入的 b6–b9 追加到末尾。
4. 8 个按需装载点只注册、不自动触发；只有显式 `window.__MOD__.ensure(名)` 才 `import()`，首屏不请求任何按需 chunk。

## 双路径与实现栈约束

`window.__WL_HAS_EL__` 的探测分支与两条渲染路径随既有层原样外置。**现阶段只走原生回落路径，增强分支不启用**。

- **构建层**：Vite（`dev` / `build`）。**模块层**：原生 ESM、零 UI 框架、零运行时依赖。
- 不引入 Vue / element-ui、不装 `@vitejs/plugin-vue`、不写 `.vue`、不注入 CDN、不模拟 `window.Vue` 点亮增强分支。
- 既有层自带的 `window.Vue`（2 处）、`window.ELEMENT`（1 处）读取点随之外置，数量与基线逐项一致；`__WL_HAS_EL__` 仍只有一处赋值且恒为 `false`，无置 `true` 代码。这些字样属于「预埋但不可达」，不是「引入 Vue」。
- 可复跑校验：`对账/无Vue约束校验.cjs`（26 项，静态 + 运行时）。

## 怎么预览（三种方式，任选一种）

**不能双击 `dist/index.html`**：产物是原生 ES module + `./assets/` 相对路径，`file://` 协议会被浏览器 CORS 拦下，必须走 HTTP。

| 方式 | 命令 | 打开 | 适用 |
|---|---|---|---|
| A · 零安装（最快） | `cd dist` → `python3 -m http.server 8080` | http://localhost:8080/index.html | 只想看效果，已实测通过 |
| B · 开发模式 | `npm install` → `npm run dev` | http://localhost:5173/ | 改代码、热更新、调模块 |
| C · 生产构建预览 | `npm run build` → `npm run preview` | http://localhost:4173/ | 验证构建产物 |

方式 A 已用 `对账/预览验证.cjs` 实测：回归 8/8、层检查 ok、冻结层 42、列表 10 行、页面错误与外部请求均 0。端口被占用时换一个即可，例如 `python3 -m http.server 8081` 或 `npm run dev -- --port 5174`。

想对照原版效果：`对账/基线原件.html` 是单文件自包含 HTML（全部内联脚本、无 module），可以直接双击用 `file://` 打开，与构建页做并排比对。

## 改代码之后怎么重生成

`index.html`、`src/层/`、`src/业务/表单/公式引擎.js`、`src/boot/层注册表.js`、`src/boot/启动入口.js` 都是 `工具/真拆生成.py` 的产物，**不要手改**，改了会在下次生成时被覆盖。要改基线逻辑，改源文件副本后按下面顺序复跑：

```bash
node 对账/导出基线层序.cjs          # 基线变动时先导出冻结层序
python3 工具/真拆生成.py
npm run build
```
